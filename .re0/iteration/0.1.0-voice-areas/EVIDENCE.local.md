## Open rows — defects and untested risks (RETRO L5: every risk exits as a row)

| Item | Status | Note |
| --- | --- | --- |
| Level scale mismatch | **unmet** | `capture.onLevel` emits RMS×4 clamped 0..1; `settings-panel.tsx` draws both the bar and the VAD threshold marker against `VAD_MAX = 0.06` on the raw RMS scale, so the bar reads ~4× high against its own marker and the founder cannot set the threshold by eye (measured live: near-silence 0.0045 vs threshold 0.012). Owner unassigned — a contract decision about scale, not a module bug (RETRO L6, gate N12). |
| `dropped` / `lastDropped` not rendered | **unmet** | Both reach `VoiceStatus`; `toolbar.tsx` shows only pending/failed, so a filtered transcript and a silent room look identical on the panel (RETRO L2, gate N10). |
| Capture path on real hardware | **untested** | Worklet path, ScriptProcessor fallback, resume-after-gesture, clock-offset drift, WAV cut accuracy: offline arithmetic plus Chromium's fake device only. Cold-start suspend probe on the panel unrun (RETRO L8, gate N13). |
| `utteranceSession` never deleted from | **untested** | Every utterance the page hears keeps a strong reference to its Session, so `sessions.delete(owner)` frees nothing on a kiosk that never reloads (RETRO L6). |
| `FailedEntry` for a deleted shape | **untested** | Never pruned; `retryFailed` skips it on the `findPair` miss and its WAV stays in memory until MAX_FAILED evicts it. Evicted entries also keep `entry.failed = true`, so that shape shows "⚠ STT" with no retry and no clear. |
| Multi-touch second contact | **accepted, not tested** | A second pointer-down before the first pointer-up overwrites `currentStroke`; the first contact's ink is never converted. IR frame behaviour unknown until the kiosk pass. |
| `fit.discard` / `markFailed` restore | **accepted, not tested** | Drawn geometry is restored unconditionally, so a user resize while a transcript is pending is snapped back. The contract gives `fit` no way to tell its own growth from a user edit. |
| `stop()` truncates the last utterance | **accepted, not tested** | Disarm closes the utterance at wall-clock `now()`, ahead of the last delivered sample, so the final clip of every take loses its 250 ms tail. Lens severity: minor. |
| Arm-window strokes | **accepted, not tested** | `armBody` switches to freedraw and renders armed before awaiting `capture.prepare()`/`start()`; strokes drawn in that window are raw ink. Milliseconds warm, seconds on a cold first arm. |
| "Subtitles by amara.org" | **accepted, not tested** | Escapes `isHallucination`: both halves are blocklisted, the joined 22-char phrase exceeds either entry + 3. Pinned as a KNOWN GAP test. Fix is one `HALLUCINATION_BLOCKLIST` entry — a contract decision. |
| `status.utterances` / `orphans` reset per arm | **accepted, documented** | `contracts.ts` defines them "since arm"; `completed` and `maxPendingSeen` stay cumulative. Any future gate asserting a cumulative count across arms will read low. |
